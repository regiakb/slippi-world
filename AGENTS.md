## Learned User Preferences
- El usuario quiere que todo el texto visible en la UI del proyecto este en ingles.
- El usuario prefiere que el asistente le hable en castellano.
- El usuario prefiere visualizaciones con porcentajes claramente visibles junto a los totales, y etiquetas claras en conteos (por ejemplo «games» en lugar de abreviaturas opacas).
- El usuario prefiere mostrar iconos de personajes cuando se muestra el nombre del personaje.
- El usuario quiere que las paginas de la plataforma usen ancho completo y un layout responsive.
- Para resumenes de mejor y peor matchup, el usuario quiere un minimo alto de partidas consideradas (por ejemplo al menos 100).

## Learned Workspace Facts
- El proyecto trabaja con estadisticas de partidas de Slippi y paneles de visualizacion.
- El repositorio usa Bun para desarrollo y ejecucion.
- La ingesta de archivos `.slp` no calcula SHA256 por archivo (se elimino por rendimiento o simplicidad).
